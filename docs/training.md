# Обучение

Значения — в [configs/base.yaml](../configs/base.yaml), отличия моделей — в `configs/experiments/`.

| Параметр | Значение | Откуда |
|---|---|---|
| Вход / резюме | 512 / 128 токенов | Вход как у авторов; резюме 84 → 128, см. [data](data.md#длины-и-обрезка) |
| Генерация | 4 луча, length penalty 0,6, запрет повтора биграмм | Как у авторов |
| Оптимизатор | AdamW, weight decay 0,01, клиппинг 1,0 | Как у авторов при обучении на одном языке (клиппинг наш) |
| Расписание | Линейный разогрев 5%, линейное затухание | Как у авторов, у них разогрев 10% для одного языка |
| lr | 5e-4; 1e-4 для дообучения эталона | У авторов 5e-4; малый lr — чтобы не разрушить уже обученную модель |
| Сглаживание меток | 0,1 | Как у авторов |
| Батч | 16 на шаг, накопление 2 (32 примера); mT5-small 32 × 1 | По памяти T4 |
| Эпохи | 2; дообучение эталона 1 | По бюджету: примерно 4,4 ч на эпоху mT5-base |
| Примеров за эпоху | 20 000 на язык, 180 000 всего | Баланс языков |
| Выбор чекпойнта | Лучший macro ROUGE-2 на 500 × 9 документах val в конце эпохи | [Протокол](experiment_protocol.md) |

У авторов есть и другой рецепт для многоязычной модели: Adafactor, батчи из одного языка, кластер из 8 GPU, четыре дня.
Такой бюджет нам недоступен, поэтому используется рецепт попроще.

## Как устроен запуск

Ядро Kaggle типа `script` — один файл, а обучение — пакет. Поэтому `src/` едет приватным датасетом, а ядро — это стаб, который
кладёт пакет на `sys.path` и вызывает `src.train.main` с явными ключами. Хэш кода передаётся ключом `--expect-code-hash`:
трейнер падает на первой секунде, если приехала другая версия. Полный рецепт хранится в `training_log.json`.

## Две GPU

На каждую T4 — свой процесс и `DistributedDataParallel`. Все процессы видят один порядок батчей и берут из него свою часть.
Решения, которые должны совпасть (пропуск батча с NaN, остановка по времени), принимаются совместно. Генерацию процессы делят
поровну: документы берутся по очереди из списка, отсортированного по длине.

## Скорость на двух T4

Замер на mT5-base (100 шагов, `xlsum-smoke`):

| Конфигурация | Примеров в секунду | Документов генерации в секунду |
|---|---:|---:|
| Одна T4, bf16 | 3,2 | 2,0 |
| Две T4, fp16 | 11,3 | 5,4 |

Итог ускорения обеспечен тремя решениями: две GPU, fp16 вместо эмулированного bf16 и применение головы только к настоящим
токенам (`SummarizerLoss`). Отдельно их вклад не измерялся.

## Экономия памяти

mT5-base занимает на GPU около 9 ГБ из 14,6 ещё до прямого прохода: веса 2,3 ГБ, градиенты 2,3 ГБ, состояние Adam 4,6 ГБ. Поэтому
включён gradient checkpointing, а логиты считаются только на настоящих токенах: при 250 тысячах слов словаря логиты всего батча с
паддингом занимали бы примерно 1 ГБ.
