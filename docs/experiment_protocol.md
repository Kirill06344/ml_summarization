# Протокол экспериментов

Записан **до** первого обучения. Изменения после просмотра результатов отмечаются в разделе «Отклонения».

## Правила

- **Главная метрика:** macro-среднее ROUGE-2 F1 по 9 языкам (`src/metrics.py`). ROUGE-1 и ROUGE-L — вторичные.
- **Выбор чекпойнта:** лучший macro ROUGE-2 на фиксированной подвыборке val (500 документов на язык, `stable_subset`).
- **Выбор финальной модели:** только по тем же 500×9 документам val.
- **Test:** прогнозы на 2000 документах каждого языка пишет каждое ядро, но оцениваются они только у эталона,
  победителя по val и бейзлайнов, один раз и после выбора. Модели, не прошедшие отбор, на test не оцениваются.
- **Сравнение:** парный bootstrap по документам внутри каждого языка, 2000 итераций, 95% CI разности (`tools/score.py`).
  Различие считается установленным, если CI не содержит нуля и |Δ| ≥ 0,3 п. ROUGE-2 — меньше этого разница не видна
  в качестве резюме. CI описывает случайность выборки документов, а не обучения: один seed не даёт оценки разброса
  запусков.
- **Сид:** 1 во всех прогонах. Подвыборки val и test не зависят от сида.

## Гипотезы и предсказания

| № | Прогон | Гипотеза | Предсказание macro ROUGE-2 на val | Действие по результату |
|---|---|---|---|---|
| B | `baseline-lead`, `baseline-textrank`, `baseline-oracle` | Простые методы задают нижнюю границу, oracle — потолок выбора одного предложения | lead и TextRank 5–10, oracle 20–30 | Модель, не обгоняющая lead и TextRank, считается неудачной |
| R | `xlsum-reference` | Эталон авторов воспроизводится нашим трактом | ≈ 13–16 (у авторов со стеммингом 15,4 в среднем по этим языкам) | Проверка тракта — индонезийский на test: у скорера авторов для него нет стеммера, а у них R-2 17,02. Расхождение больше 2 п. — ошибка в тракте, сначала разобраться |
| H1 | `xlsum-mt5-small` | Даже малая модель обгоняет бейзлайны | 9–13 | Не обогнала — проверить обучение до следующего прогона |
| H2 | `xlsum-mt5-base` | Большая модель лучше малой | на 1–3 п. выше H1 | Сравнить с H3 |
| H3 | `xlsum-mt5-xlsum-finetune` | Дообучение эталона на наших языках выше эталона | на 0–1 п. выше R | Побеждает — финальная модель; иначе финальная — лучшая из R и H2 |

## Бюджет

Не более 25 GPU-часов T4 на всю работу, не больше двух ядер одновременно. Сначала короткий `smoke` (скорость, fp16).
Если mT5-base не укладывается в отведённые 10 ч, сокращается `train_per_language`, а не обрезка входа, и
это записывается ниже.

## Отклонения

1. **До обучения:** `max_target` 128 вместо 84 авторов у всех моделей, включая эталон. Причина: при 84 обрезается 32%
   вьетнамских резюме (0,9–10,3% у остальных языков; выборка 3000 резюме train на язык). Числа эталона по вьетнамскому
   могут отличаться от таблицы авторов и в лучшую сторону.
2. **До обучения:** фактические бейзлайны на val оказались ниже предсказанных (lead 5,88; TextRank 4,96; oracle 14,78).
   Правила из-за этого не менялись.
3. **До обучения:** по замеру на двух T4 (11,3 примера/с, 5,4 документа/с при генерации) эпох стало меньше: mT5-small и
   mT5-base — 2, дообучение эталона — 1. Прогнозы на test у mT5-small не пишутся; если она неожиданно победит по val,
   они будут получены отдельным запуском.
4. **До результатов обучения:** официальный скорер авторов не используется: установка его кода из GitHub запрещена
   настройками разрешений среды. Все числа считает `src/metrics.py` без стемминга, поэтому сравнение с таблицей авторов
   строго корректно только для языков без стеммера в их скорере. Проверка тракта перенесена на индонезийский язык.
